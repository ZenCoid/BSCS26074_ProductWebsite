# BSCS26074 Product Website

This repository contains an interactive e-commerce product website developed as part of the Applications of ICT lab curriculum. The website features a home page, product showcase page, and a contact page designed to demonstrate client-side interactivity using modern web development standards.

The project was built using HTML for structural layout, CSS for custom styling, and JavaScript for dynamic behavior. Core interactive capabilities include automated page alerts, dynamic footer year generation, interactive stock availability toggles, and form input validation.
